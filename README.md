## 🌟 Overview
**HACKNOVA 2026** is a single-page hackathon web portal designed with an arcane, dark-themed magical aesthetic inspired by Hogwarts and NexHack. It features glowing gold borders, arcane particle embers, interactive modals, responsive winding train timeline, and custom department branding.

---

## ⚡ Key Features

1. **Session-Based Video Intro:**
   - Fullscreen cinematic video intro on first launch per browser session (`sessionStorage`).
   - Prominent **"Registration"** overlay button that instantly silences and dismisses the intro.
2. **Magical Characters Banner:**
   - Platform 9¾ chibi character banner with floating particle effects.
3. **Winding Hogwarts Express Schedule Timeline:**
   - Animated top-down train cruising along a golden S-curve track.
   - Day-time event schedule (10:00 AM – 4:00 PM).
4. **8 Modern Hackathon Problem Statements:**
   - AI-Powered Urban Mobility
   - Smart Education and Classroom Analytics
   - Smart Tourism and Public Safety
   - Digital Trust and Product Authentication
   - Preventive Healthcare and AI
   - Healthcare Cybersecurity
   - Smart Water Infrastructure
   - Smart Supply Chain and Food Safety
5. **Title Sponsor Spotlight:**
   - [CodroidHub Pvt Ltd](https://codroidhub.com/our-platforms) ecosystem & platforms showcase.
6. **Organizing Committee:**
   - **Council of Arch-Mages** (Faculty Leadership, Institutional Head Gp Capt CS Sharma, and Sponsor's CEO).
   - **Order of the Phoenix** (Lead Student Coordinator: Sanjana).
7. **Glimpses of ACE:**
   - Visual masonry gallery capturing campus events, incubation seminars, and robotics labs.
8. **Registration Chamber:**
   - Verified registration flow with fee details (₹50) and direct Google Form link.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/sanjana806/HACKNOVA-.git
cd HACKNOVA-
```

### 2. Run Locally
You can simply open `index.html` in any modern web browser, or launch a lightweight local server:

```bash
# Using Python
python -m http.server 8000
```
Then visit `http://localhost:8000/`.
